# Standard editorial CTL

1. Păstrează cele 40 de rubrici originale și anexa Dividend Kings; nu redenumi și nu elimina rubrici fără aprobare.
2. Fiecare cifră trebuie să aibă instrument/indicator, unitate, momentul observației, momentul colectării și sursă.
3. Separă explicit: FAPT CONFIRMAT, ESTIMARE, DATE INTRADAY, DATE DEMO și INTERPRETARE CTL.
4. Nu confunda închiderea oficială cu ultima cotație intraday și nu combina fusuri orare fără etichetare.
5. Pentru date oficiale, prioritizează emitentul/instituția: BVB, BNR, INS, Eurostat, ECB, Federal Reserve, Treasury etc.
6. Presa și agregatoarele sunt surse secundare; confirmă evenimentele importante în documente primare.
7. Pentru dividende: verifică hotărârea AGA/CA, ex-date, data plății, brut/net, fiscalitate și sursa oficială.
8. Pentru Dividend Kings: verifică separat numărul de ani consecutivi, randamentul, data prețului și siguranța dividendului; randamentul nu este garanție.
9. Dacă o sursă nu poate fi accesată sau o informație nu poate fi confirmată, marchează explicit limita.
10. Corecțiile nu șterg istoricul: notează valoarea veche, valoarea corectată, motivul, sursa și ora corecției.
